# Custom Branding Assets

Place your custom branding files here and uncomment the COPY lines in the Dockerfile.

## Required Files

| File | Size | Purpose |
|------|------|---------|
| `favicon.png` | 32x32 or 64x64 px | Browser tab icon |
| `logo.png` | ~200x200 px | Login page / sidebar logo |
| `splash.png` | ~400x400 px | Loading splash (light theme) |
| `splash-dark.png` | ~400x400 px | Loading splash (dark theme) |
